# 熊的日记 🐻

一个像素风、温暖治愈的互动叙事网站。

## 流程

1. **熊的小屋** —— 一只熊和六件物品（蜂蜜罐、红雨伞、旧围巾、小提灯、橡果、口琴）
2. 点击任意一件物品，进入它的**日记本**：点击翻页阅读故事，最后一页写下你的看法
3. 写完返回小屋，继续选下一件物品；全部听完后，物品上会亮起爱心徽章
4. 六个反馈都写完，进入**毛毡板**：你的六段话被钉在便签上，并问你「是否有要分享的故事」
5. 分享（或跳过）后，进入**最后一个界面**：黄昏的星空下，熊走在一条路上，带着你的故事

## 如何运行

零依赖，直接双击 `index.html` 用浏览器打开即可。

也可以起一个本地服务：

```bash
npx serve .
# 或
python -m http.server 8000
```

## 如何修改

| 想改什么 | 改哪个文件 |
| --- | --- |
| 六个物品的名字、日记故事、提问 | [stories.js](stories.js)（每页一个字符串，保持简短） |
| 像素图案（熊、物品、爱心） | [pixel.js](pixel.js)（字符画，每行等长，`.` 为透明） |
| 配色、字体、翻页动画、便签样式 | [styles.css](styles.css) |
| 交互流程、场景布局、动画逻辑 | [app.js](app.js) |
| 页面结构 | [index.html](index.html) |

### 故事格式说明（stories.js）

```js
{
  id: 'honey',            // 唯一标识，对应 pixel.js 里的 item_honey 精灵
  name: '蜂蜜罐',          // 物品名
  diary: '关于甜的一页',    // 日记封面小标题
  color: '#e8a33d',       // 主题色（毛毡板便签圆点、提问左边框）
  prompt: '关于甜，你有没有想对熊说的话？',
  pages: ['第一页……', '第二页……', '第三页……'],
}
```

## 其他说明

- **进度持久化**：反馈、分享的故事、所处阶段存在浏览器 `localStorage` 中，刷新不丢失。结尾的「回到小屋，再听一次」会清空全部数据重新开始。
- 每个日记页面建议控制在 100 字左右，超出会自动出现滚动条。
- 全程无网络依赖（无 CDN 字体/图片），离线可用。
